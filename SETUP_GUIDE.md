# CryptoINC — инструкция по настройке (для новичков)

> Этот гайд написан максимально просто. Если где‑то застрянешь — просто напиши, на каком шаге, и что именно видишь на экране.

---

## 1) Установка программы (Windows)

1. Открой раздел **Releases** на странице проекта.
2. Скачай установщик `CryptoINC Setup ... .exe`.
3. Запусти файл и установи приложение как обычную программу.

### Возможное предупреждение Windows

Если Windows покажет “неизвестный издатель / SmartScreen”:
- Нажми **Подробнее**
- Нажми **Выполнить в любом случае**

---

## 2) Подготовка Binance API (нужно для торговли)

**Зачем это нужно:** приложение подключается к твоему аккаунту Binance, чтобы читать баланс/позиции и (если ты разрешишь) выставлять ордера.

### Шаги

1. Зайди на Binance в браузере.
2. Открой **Account → API Management**.
3. Нажми **Create API**.
4. Включи разрешения:
   - ✅ Reading
   - ✅ Spot & Margin Trading
   - ✅ Futures (если используешь фьючерсы)
5. **Обязательно выключи и никогда не включай**:
   - ❌ Withdrawals (вывод средств)

После создания Binance покажет:
- **API Key**
- **Secret Key**

Сохрани их в надёжное место (лучше менеджер паролей).

---

## 3) Ввод ключей в CryptoINC

1. Открой CryptoINC.
2. Зайди в **Настройки → Binance API**.
3. Вставь **API Key** и **Secret Key**.
4. Нажми **Проверить и сохранить**.

Если проверка не проходит:
- проверь, что ключи вставлены без лишних пробелов
- проверь, что включены нужные разрешения (Reading/Trading)
- если включён IP‑whitelist в Binance — добавь свой IP

---

## 4) Настройка AI (необязательно)

### Вариант A — локальный AI (Ollama)
**Плюсы:** приватность, скорость, ключи никуда не отправляются.  
**Минусы:** нужна установленная Ollama и место под модель.

1. Установи Ollama: `https://ollama.com`
2. Скачай модель (пример):

```bash
ollama pull qwen3.5:9b
```

3. В приложении выбери AI‑провайдер **Ollama**.

### Вариант B — облачный AI

Если выбираешь облако (например OpenAI/Anthropic) — купи ключ у провайдера и вставь его в настройках приложения.

### Вариант C — без AI

Если AI не нужен — можешь не настраивать, приложение будет работать в базовом режиме (в зависимости от сборки).
