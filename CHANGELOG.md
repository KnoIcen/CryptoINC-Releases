# История изменений (CryptoINC — пользовательские сборки)

Формат: кратко, что меняется между установщиками на странице [Releases](https://github.com/KnoIcen/CryptoINC-Releases/releases).

Исходники и CI: репозиторий [KnoIcen/CryptoINC](https://github.com/KnoIcen/CryptoINC).  
Сервер лицензий (аккаунт/подписка): [KnoIcen/CryptoINC-License-Server](https://github.com/KnoIcen/CryptoINC-License-Server).

---

## [1.0.12](https://github.com/KnoIcen/CryptoINC-Releases/releases/tag/1.0.12) (текущий установщик)

- **Первый запуск**: после регистрации — мастер настройки (уровень опыта → Ollama → Binance API → ключ подписки с пропуском и предупреждением → Telegram, если ключ введён).
- **Вход / аккаунт**: быстрее закрывается окно авторизации; подписка может приходить уже в ответе на логин (меньше лишних запросов к серверу лицензий).
- **Авто‑трейдер**: без «мигания» окна подписки, если ключ уже активирован; меньше дублей в журнале активности.
- **Binance Live**: индикатор в сайдбаре раньше показывает «живые» данные (в т.ч. пока идёт только REST‑снимок).
- **AI Chat + Ollama**: устойчивее разбор ответа (JSON и потоковые NDJSON‑фрагменты).
- Удалена шуточная кнопка «Похвалить Китай» из интерфейса авто‑трейдера.
